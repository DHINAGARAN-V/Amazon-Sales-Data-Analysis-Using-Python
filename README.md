# Amazon Sales Data Analysis Using Python

## Project Overview

This project analyzes the Amazon sales dataset using Python to understand sales performance, customer purchasing behavior, and product trends. The analysis uses Python libraries to clean, process, and visualize the dataset to generate meaningful insights.

## Objectives

* Analyze overall Amazon sales performance
* Identify top-selling products and categories
* Evaluate revenue trends and customer purchasing behavior
* Generate insights using Python-based data analysis

## Analysis Features

* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Sales trend visualization
* Product and category performance analysis

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Amazon Sales Dataset

## Key Insights

* Identification of top-performing products and categories
* Insights into customer purchasing patterns
* Visualization of revenue and sales trends
* Business insights derived from data analysis

## Files in This Repository

* `amazon_sales_analysis.ipynb` → Python analysis notebook
* `amazon_sales_dataset.csv` → Raw dataset used for analysis
* `images/` → Visualization charts and analysis outputs

## Dataset

Amazon Sales Dataset used for analyzing sales performance, product demand, and customer purchasing behavior.
